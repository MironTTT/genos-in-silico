# Genos-in-Silico

**Genos-in-Silico** — это локальная десктопная платформа для in silico поиска лекарств (De Novo Drug Discovery). Система объединяет генеративный ИИ для создания новых молекул с детерминированной физиологической симуляцией, чтобы предсказывать, как препарат будет вести себя в организме человека.

Платформа проектируется как **масштабируемая** (disease-agnostic). Первый целевой модуль — заболевания желудочно-кишечного тракта (гастрит), так как для них существуют эталонные препараты для валидации моделей.

## Пайплайн (Как это работает)

Процесс проходит в три этапа: от генерации молекулы до симуляции её эффекта на клетки.

### 1. Генерация и Фильтрация
*   **Генератор (VAE):** Вариационный автоэнкодер, работающий со строками SMILES. Генерирует, скрещивает и модифицирует молекулы в латентном пространстве.
*   **Физико-химический арбитр:** Жесткий фильтр на базе RDKit. Отсекает молекулы с плохой липофильностью (LogP), токсифорами или весом > 500 Да до того, как они попадут в симуляцию.

### 2. Фармакокинетика (PBPK)
Молекулы, прошедшие фильтр, попадают в 5-компартментную PBPK-модель (*Physiologically Based Pharmacokinetics*). 
*   **Компартменты:** ЖКТ, Кровь, Печень, Почки, Целевой орган.
*   **Динамика:** Система дифференциальных уравнений рассчитывает концентрацию препарата в органах с учетом кровотока, метаболизма и клиренса.
*   **Вариативность пациента:** Пользователь может менять параметры (например, «здоровье почек» или «состояние печени»), и коэффициенты уравнений пересчитываются на лету.

### 3. Модель заболевания
*   **Целевой орган:** Препарат воздействует на модель патологии (например, баланс pH в желудке при гастрите).
*   **Терапевтический индекс:** Система оценивает не только эффективность препарата, но и его нейротоксичность или повреждение здоровых тканей при превышении дозировки.
